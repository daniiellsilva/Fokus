# 🎯 Fokus — Temporizador de Foco

Projeto desenvolvido durante o curso **“Manipulando elementos no DOM”**, da **Alura**, com o instrutor **Luan Alves**.

## 📚 Sobre o projeto

O **Focus** é uma aplicação de temporizador que permite alternar entre diferentes momentos:

* 🎯 **Foco**
* ☕ **Descanso curto**
* 🌴 **Descanso longo**

O projeto foi desenvolvido com **HTML, CSS e JavaScript**, com foco na manipulação de elementos do **DOM (Document Object Model)**.

## 🛠️ Conceitos praticados

Durante o desenvolvimento, foram utilizados diversos recursos do JavaScript para manipulação e interação com a página:

### `innerHTML`

Utilizado para **alterar os textos exibidos na tela**, como títulos e informações relacionadas ao temporizador.

### `setAttribute`

Utilizado para **alterar atributos dos elementos HTML**, principalmente o caminho (`src`) das imagens exibidas de acordo com o contexto selecionado.

### `classList`

Utilizado para **adicionar, remover e alterar classes CSS**, permitindo modificar os estilos dos botões de:

* Foco
* Descanso curto
* Descanso longo

### `querySelector`

Utilizado para **selecionar e acessar elementos HTML** diretamente pelo JavaScript.

### `addEventListener`

Utilizado para **escutar as interações do usuário com a página**, como os cliques nos botões e outras ações necessárias para controlar o temporizador.
